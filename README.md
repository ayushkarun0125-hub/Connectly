# CSCI 2020U Project Charter & Work Contract — Group 53

## 1. Project Overview

* **Project Members:** Dhruv Thakar, Ayush K., Aaryan Kulkarni
* **Product Name:** Connectly
* **Project Description:** Connectly is a real-time multi-room chat application where users pick a username, join chat rooms, and exchange messages instantly with other connected users. Level Up features include sound notifications on new messages (Howler.js), a typing indicator, emoji picker, and a dark/light mode toggle.
* **Tech Stack:** Node.js + Express (Server / Threading via event loop), Socket.io (WebSockets / equivalent to Java Sockets), React + Tailwind CSS (GUI), Node.js `fs` module with JSON (Persistence / File I/O), Howler.js (Sound)
